Install the root CA to decrypt HTTPS

JASniffer signs per-site certificates with its own root CA. Until you trust it, HTTPS sites will warn. On Windows just press Install CA (one-time consent prompt, no admin) — Chrome/Edge will trust it. Firefox uses its own store: use Download CA and import it. Then choose System mode or point your app at 127.0.0.1:8866.

Настройки

Режим захвата
System — системный прокси ОС (весь трафик, Windows). Manual — ловится только то, что направлено на 127.0.0.1:8866.
JA3 / отпечаток апстрима
TLS (JA3) + HTTP/2 отпечаток, с которым запрос уходит наверх. Выберите пресет и нажмите Применить.
Протокол и поведение
Апстрим‑прокси (исходящий)
Весь исходящий (апстрим) трафик идёт через прокси; расшифрованные сессии вы по‑прежнему видите. Форматы: http://user:pass@ip:port, socks5://ip:port, ip:port, ip:port:user:pass. Учётные данные не URL‑кодируются в поле.
Пропускать без расшифровки (хосты)
По строке/через запятую. Эти хосты идут сырым туннелем (без MITM) — для сайтов с pinning или тех, что ломаются при перехвате. Хост охватывает и поддомены (ls.app → cdn.ls.app). В списке видны как «tunnel».
