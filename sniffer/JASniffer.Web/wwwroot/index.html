Install the root CA to decrypt HTTPS

JASniffer signs per-site certificates with its own root CA. Until you trust it, HTTPS sites will warn. On Windows just press Install CA (one-time consent prompt, no admin) — Chrome/Edge will trust it. Firefox uses its own store: use Download CA and import it. Then choose System mode or point your app at 127.0.0.1:8866.
